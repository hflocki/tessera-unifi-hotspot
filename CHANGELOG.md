# Changelog

## 0.2.0
- Any size from 1x1 to 6x6. A 1x1 tile shows the QR code alone; larger tiles add the code, the network's name, the
  validity and the keys as they fit.
- New option QR code only.
- Keys too narrow for their words show an icon.

## 0.1.0
- First version: the guest Wi-Fi's QR code, the current voucher with its validity, and keys to refresh it or create a
  new one, from UniFi Hotspot Manager.
